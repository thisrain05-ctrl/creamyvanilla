# Credits

## Third-party credits

### Supplementaries - MehVahdJukaar (and Plantkillable)
The **Sack** in Creamy Vanilla is a fork of the sack from Supplementaries. The sack's code and art
(block/item models, textures, GUI, sounds) were used directly from that mod.

- Supplementaries: https://www.curseforge.com/minecraft/mc-mods/supplementaries

### Harvest with Ease - Crystal Nest
The right-click **harvesting action** (harvest a mature crop, drop its loot minus one seed, reset its age) uses
code originally from Harvest with Ease. The **Harvesting enchantment** itself is original to Creamy Vanilla, and
no art from Harvest with Ease is used.

- Harvest with Ease: https://modrinth.com/mod/harvest-with-ease

## Dependencies (not bundled)
- Puffish Attributes - optional; the Fire Resistance attribute is built on its dynamic-attribute API.
- ShulkerBoxTooltip - optional; sack contents preview in tooltips.
- Farmer's Delight - optional; extra harvestable crops.
